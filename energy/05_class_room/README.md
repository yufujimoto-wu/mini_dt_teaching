# 教室の予冷と室温

一つの教室の予冷開始時刻と室温・電力使用量を比較する授業用Streamlitデモ。

## 起動

```sh
pip install -r requirements.txt
streamlit run app.py
```

## 講義での操作例（5〜10分）

1. 初期値の45分前開始と9:00開始を比較。授業開始時の室温と電力使用量を確認。
2. 予冷を0分、30分、60分に変更。室温の変化と運転時間の関係を確認。
3. 外気温・人数・空調能力を変更。同じ運転案でも条件によって結果が変化。
4. 運転案を保存し、設定温度も変更。折りたたみ欄で同じ共通条件による比較。
5. 実際の温度・電力を観測することで、モデルの更新と運転後の効果確認につながることを説明。

## モデル

1分刻みの熱収支。7:30に共通の室温から開始し、授業は9:00〜11:00。空調終了は11:00。一定の外気温・日射、授業中のみ在室者の発熱。熱容量は空気・建物・家具を合わせた有効値。冷房出力は熱流入と設定温度との差から計算し、冷却能力で制限。消費電力は冷却出力/COP。補機や起動損失は未算入。

校正済みの建物モデルでも実測連動のデジタルツインでもなく、両者への接続を説明するための小規模シミュレーション。入力値は授業用の設定値。温度の目安は快適性・安全性の公的基準ではない。

保存比較は運転方法のみ保存。外気温・人数・能力などを変更した場合、保存案も現在の条件で再計算。
