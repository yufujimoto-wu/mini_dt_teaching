# モンテカルロ法による水位予測

第5回の2段貯留モデルを使い、元の確定的アプリと同じ左パネル・再生操作・模式図を引き継いだ独立版です。

## 起動

Python 3.14で動作確認しています。このフォルダで実行します。

```sh
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

Cloudではapp.py、ensemble.py、model.py、requirements.txtを同じフォルダへ配置してください。
元の確定的アプリのファイルは変更していません。

## モデル

dS/dt = A r_e − Q_in, Q_in = S/τc

dV/dt = Q_in − Q_out, Q_out = V/τr

h = h0 + V/Ar

km²・万m²・mm/h・時間を内部でSI単位へ換算します。S0は流域の等価水深から水量へ換算し、V0は万m³で与えます。
h0は水位換算の基準で、初期水位はh0+V0/Arです。

## モンテカルロの設定

降雨ピーク・降雨継続時間・流域と河道の時定数・初期貯留は、中心値の±指定割合の独立な一様分布から抽出します。
例えば±0.30なら中心値の70〜130%です。これは標準偏差の指定ではありません。
降雨開始時刻は中心時刻±指定時間の一様分布です。開始が負なら予測開始前から雨が降っているケースを表し、初期貯留は独立に与えます。
中心値0に対する割合のばらつきは0です。

サンプルごとに一度だけ抽出し、そのパラメータと一貫した三角形の降雨波形で全期間を計算します。時刻ごとに降雨を独立抽出するものではありません。
同じシードなら同じサンプルになり、再描画・再生で抽出し直しません。Nを増やした場合も先頭のサンプルは維持されます。

## 表示

- 細い青線：抽出した水位軌跡の一部。描画本数を減らしても、確率は全N本から計算します。
- 太い青線：各時刻の標本平均水位。
- 水色の帯：各時刻の5〜95%分位点。軌跡全体の同時被覆区間や平均値の信頼区間ではありません。
- 橙色の線：左パネルで選んだシナリオ。模式図もこの1本に対応します。
- 模式図の水面倍率は全シナリオを考慮して固定します。矢印の倍率は選択シナリオの全期間で固定します。

再生は計算済みの予測軌跡を順に見せる操作です。新しい観測で分布を更新するデータ同化ではありません。

## 超過確率

判定は h > 基準水位（等号を含まない）です。

1. 各時刻の超過確率：その時刻に超えている本数 / N。
2. 再生時刻までに一度でも超過：時刻0〜再生時刻の最大水位が基準を超えた本数 / N。
3. 指定期間の超過確率：時刻0〜左パネルの評価終了時刻までの最大水位が基準を超えた本数 / N。

上部の期間確率は計算済み予測全体から求めるので、再生を進めても変わりません。評価終了時刻の既定値は3時間です。
赤い累積確率線は一度超えたケースを数え続けるため下がりません。各時刻の確率の最大値とは異なります。

95%のWilson区間は有限な独立標本に伴うモンテカルロ標本誤差の目安です。
入力分布や独立性の仮定の誤り、モデル誤差、時間離散化誤差を含みません。0/NやN/Nでも真の確率が0や1と確定したことにはなりません。

30秒刻みで区間中点の降雨を一定近似し、線形連立式を解析的に更新します。
基準超過は数値格子上の判定であり、非常に短い超過を取り逃す可能性があります。任意時刻を指定した場合は隣接格子の水位を線形補間します。

## 授業用の設定例

各例を選び、「全時間を表示」を押してください。再生して軌跡が増える時間変化を見せることもできます。

- ① ばらつきなし：すべての幅を0にし、元の確定的な1本に重なることを確認。
- ② 降雨だけにばらつき：雨の量・時刻・長さのばらつきが水位に伝わる様子。
- ③ 降雨と時定数にばらつき：入力とモデルパラメータの両方を変化。
- ④ 標本数を増やす：既定分布のままN=1000。N=50,100,200,500,1000やシード変更で推定のばらつきを比較。

既定のN=200、シード42、基準水位1.4 m、評価期間0〜3時間では117/200=58.5%です。
30秒刻みを15秒刻みに細かくした確認でも、この設定の超過本数は117本でした。
これは授業用に仮定した分布とモデルから得た例で、実際の河川の較正された超過確率ではありません。

## データ保存

「抽出したパラメータ・期間内最高水位・データ保存」でパラメータ表、指定期間の最大水位と超過判定、分位点と確率の全期間時系列をCSV保存できます。

潮位・背水・氾濫は対象外です。超過しても水の流れの式は変わりません。
