# 2流域の降雨相関と合流後の水位

元のモンテカルロ水位アプリの操作体系を引き継いだ、独立した相関のデモです。
両流域の降雨ピーク強度は同じ一様分布で、相関の変更では標本の組合せだけを変更します。

## 起動

Python 3.14で動作確認しています。このフォルダで実行します。

```sh
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

Cloudにはapp.py、ensemble.py、model.py、requirements.txtを同じフォルダへ配置します。
既存アプリは変更していません。

## 最初に見せる操作

1. 既定条件で「全時間を表示」。
2. 左上の「負 −1」「無相関 0」「正 +1」を順に押す。
3. 散布図は変わるが、2流域のヒストグラムは変わらないことを確認する。
4. 水位の平均線が変わらず、帯の幅と高い基準水位の超過率が変わることを確認する。

相関を変更しても現在の再生時刻は維持し、一時停止します。他のモデル条件の変更は時刻0へ戻します。

既定条件：各流域2.5 km²、時定数はいずれも0.8時間、河道時定数0.5時間、降雨ピークの中心40 mm/h・範囲20〜60 mm/h、降雨時刻0.5時間・継続2時間。
基準水位1.7 m、評価期間0〜3時間、N=200、シード42の例：

| 相関の目標 | 実際の標本相関 | 期間内の超過率 |
| --- | --- | --- |
| -1 | -1 | 0% |
| 0 | 約0.000057 | 13% |
| +1 | +1 | 27% |

基準水位の位置や流域条件によって結果は変わります。正の相関で超過率が常に上がるという一般則を示すものではありません。

## 分布を同じに保つ方法

一様分布をN個の等確率区間に分け、各区間の中点を共通の降雨ピーク標本とします。
同じ標本の並びを変えて流域1と2の組を作るため、平均・分散だけでなくヒストグラム全体が相関変更の前後で同じです。

シードから生成した2列の正規乱数を使い、相関したスコアの順位に従って共通標本を並べ替えます。
スコアの相関パラメータを調整し、最終的な降雨ピークのPearson標本相関を目標に近づけます。
有限標本の順位組合せなので、目標と完全一致するとは限りません。実際の標本相関を上部に表示します。

流域1の並びは相関変更では固定され、流域2の並びだけが変わります。±1では完全な同順・逆順です。
乱数シードの変更で組合せ方が変わります。標本数Nの変更では等確率区間そのものが変わります。

これは層化した周辺標本を固定する順位組替え型のモンテカルロ実験です。
各組を独立な単純無作為抽出とみなせないため、従来版の二項分布に基づくWilson区間は表示しません。
「無相関0」は独立性の保証ではありません。相関係数だけで依存構造のすべてを指定しているわけでもありません。

参考：
- [SciPy：層化した周辺標本（LatinHypercube）](https://docs.scipy.org/doc/scipy-1.15.0/reference/generated/scipy.stats.qmc.LatinHypercube.html)
- [MathWorks：コピュラを使った依存関係の生成](https://www.mathworks.com/help/stats/simulating-dependent-random-variables-using-copulas.html)

本実装は上記ライブラリ関数を呼ばず、等確率中点・正規スコアの順位組替え・有限標本相関の調整を実装しています。

## 物理モデル

各流域 j=1,2：dS_j/dt = A_j r_j − S_j/τ_j、Q_j = S_j/τ_j。

合流後：dV/dt = Q_1 + Q_2 − V/τr、h = h0 + V/Ar。

降雨の開始時刻と継続時間は両流域で共通・全シナリオで固定です。
流域面積・時定数などの物理パラメータと初期貯留もシナリオ間で固定し、降雨ピークの相関の影響に絞っています。

初期S1,S2は共通の等価水深×各流域面積。V0は合流後の河道全体の初期貯留です。
h0は初期水位ではなく水位の換算基準で、初期水位はh0+V0/Arです。

モデルの線形性を使い、各流域の初期状態の応答と単位降雨の応答を重ね合わせて計算します。
河道の初期V0は計算上2分割して各応答へ与えますが、物理的には合流後に1つの河道があるモデルです。
10秒以下の区間ごとに降雨を一定近似し、線形貯留式を解析的に更新します。
元の確定的アプリとの一致と水収支を検証しています。

この線形モデルでは、各流域の平均入力が変わらないので、相関を変えても各時刻の平均水位は変わりません。
最高水位の平均は「各時刻の平均水位の最大」と異なるため、完全に一定とは限りません。
既定の対称条件で相関-1では両流域の降雨ピークの合計が一定となり、合流後の軌跡が重なります。
流域面積や時定数を非対称にすると、相関-1でも水位のばらつきが残り得ます。

## 超過率と表示

- 判定は水位h > 基準水位（等号を含まない）。
- 上部は予測開始0〜評価終了Tまでに一度でも超える本数/N。
- 時系列グラフは各時刻の超過率と、その時刻までの累積超過率を表示。
- 描画する細線の本数を減らしても、確率は全N本から計算。
- 水位の5〜95%帯は各時刻の分位点。軌跡全体の同時被覆ではありません。
- 模式図は選んだシナリオで、橙色の水位線と対応します。流域・河道の水面尺度は異なります。
- 水位軸と水面表示の倍率は、相関を変更しても固定されます。
- 再生は計算済みの時間変化の表示で、観測を追加する予測更新ではありません。
- 超過判定は数値格子で行います。有限標本と数値計算の近似を含みます。
