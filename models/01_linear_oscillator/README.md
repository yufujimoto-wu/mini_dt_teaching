# 線形自由振動の台車デモ

Python 3.10以降を使用します。このフォルダで次を実行してください。

```sh
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

左パネルで質量・ばね定数・減衰係数・初期変位・初期速度を変更できます。
物理条件や計算時間を変更すると時刻0に戻って停止します。
「再生」「一時停止」「先頭に戻る」で操作します。
時刻指定スライダーを動かすと、その時刻で一時停止します。
スライダーは再生位置を自動追従しません。現在時刻は数値・グラフ上の赤い点・進行バーで示します。

減衰なし、不足減衰、臨界減衰、過減衰に対応します。
例えば m=1、k=4 のとき、c=0 は減衰なし、c=0.3 は不足減衰、c=4 は臨界減衰、c=8 は過減衰です。
初期変位と初期速度がともに0なら台車は動きません。

台車の表示倍率とグラフの縦軸は初期エネルギーに応じて決まり、再生中は固定されます。
台車の絵は模式図です。観測データや外力は使用していません。
運動方程式の解析解を使用し、再生表示は約0.1秒ごとの更新を目標とします。
実際の描画間隔は環境に依存します。
