# 自由振動・センサ観測・ARモデル

既存の台車アプリをもとにした独立した追加版です。このフォルダ内の4つのPython・設定ファイルを一緒に使用します。

## 起動

Python 3.10以降で、このフォルダを開いて実行します。

```sh
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

## 基本操作

1. 左パネルで物理パラメータ、初期条件、センサの記録周期・観測誤差を設定します。
2. 再生すると、真の変位の線と台車が動き、記録時刻に達するごとに赤い×が増えます。
3. 12点以上を記録したら「現在までの記録で学習する」を押します。記録済みデータだけを使用し、再生は停止します。
4. 学習データの割合、最大次数、次数の選び方を変更して、同じ記録で再学習できます。

「全時間を記録して停止」を使うと再生を待たずに一括記録できます。時刻指定は一時停止します。
センサ条件・物理条件の変更は記録を初めからやり直し、学習結果を消します。先頭に戻る操作でも学習結果を消します。
学習結果は学習した時点の記録を固定したものです。再生を再開しても自動的に再学習しません。

## 授業用の設定例

左パネルの「授業用の設定例」を開きます。設定例を選び、「全時間を記録して停止」「現在までの記録で学習する」を順に押してください。

| 設定例 | 比較すること |
| --- | --- |
| 良好な観測 | 短い記録周期と小さい誤差で、観測・予測と真の波形を比較 |
| 過学習を比較 | 「学習誤差最小」と「BICで自動選択」を切り替えて再学習し、高次モデルの検証誤差を比較 |
| 信号がノイズに埋もれる | 観測条件が悪い場合にAR(0)が選ばれる例。小さい次数が真の運動の単純さを保証するわけではない |

同梱設定のシード42で全時間を記録した計算では、「過学習を比較」は学習誤差最小でAR(15)、BICでAR(5)となり、AR(15)の検証1ステップ誤差が大きくなります。
「信号がノイズに埋もれる」はBICでAR(0)になります。
これは特定条件の実例です。シードや条件を変更すれば選択結果は変わります。

## モデル・評価

- 観測：等間隔の真の変位に、平均0・指定標準偏差の独立正規乱数を加えます。データは再描画ごとに変わりません。
- AR(p)：過去p点から現在の観測値を最小二乗法で予測します。既定では平衡位置が既知として切片0。切片の推定も選べます。
- AR(0)：切片なしではゼロ予測、切片ありでは学習区間の共通目的値の平均です。
- 記録の前半を学習、後半を検証に分けます。次数比較の公平さのため、全候補で最大次数分の先頭記録を共通に除外します。係数は選択後も同じ学習窓の値を使います。
- データ数に応じて候補最大次数を制限し、残差の自由度を確保します。階数不足の候補は除外します。
- 自動選択：AIC、BIC、学習RMSE最小。検証区間・真の変位は次数の自動選択に使いません。
- AIC = n log(SSE/n) + 2q、BIC = n log(SSE/n) + q log(n)。qはAR係数、任意の切片、誤差分散のパラメータ数の合計。候補共通の定数を省きます。
- 検証1ステップ予測：直前のセンサ記録を逐次利用します。
- 検証連続予測：学習末尾の記録から出発し、以後の入力に予測値を使います。
- RMSEは原則としてノイズを含む記録との比較です。真の変位との誤差は参考値として別記します。ゼロ予測との比較も表示します。
- 連続予測が大きく増大した場合、観測が見えるよう波形の縦軸は固定します。範囲外はメッセージで知らせ、誤差表も確認できます。数値計算限界を超えた予測は欠損とし、誤差はinfで表示します。

線形自由振動のノイズのない等間隔標本列はAR(2)で表せます。センサノイズが加わると、記録の予測に有利な次数が2とは限りません。
自由振動は非定常で後半の振幅が小さくなるため、低い検証RMSEだけで予測品質を判断せず、波形やゼロ予測も比較してください。
同じ検証区間を見ながら条件を調整した場合、最後は新しい乱数シードや別条件で確認してください。

次数比較で同じ学習窓を使う考え方の参考：
[statsmodels AutoReg（hold_back）](https://www.statsmodels.org/stable/generated/statsmodels.tsa.ar_model.AutoReg.html)
