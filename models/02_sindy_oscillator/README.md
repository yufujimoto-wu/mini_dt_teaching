# 台車の運動から方程式を探す：SINDy

既存の台車・センサ・ARモデルのアプリから独立したデモです。
左パネル、台車のアニメーション、変位のグラフ、再生・停止・時刻指定を引き継いでいます。

## 起動

Python 3.14で動作確認しています。同梱のrequirements.txtは動作確認したバージョンに固定しています。
このフォルダで実行してください。

```sh
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

Streamlit Cloudではapp.pyと同じフォルダにrequirements.txt、oscillator.py、discovery.pyを配置してください。
既存アプリとは別のエントリポイントでデプロイできます。

## 授業での操作

各設定例を選んだ後、「全時間を記録して停止」→「記録から式を学習する」を押してください。
再生して赤い×が増える様子を確認してから、記録済みの範囲だけで学習することもできます。
候補項・しきい値・微分方法の変更は記録を維持して学習結果を消します。再学習してください。
物理条件・センサ条件を変更すると時刻0に戻ります。学習結果は学習時点の記録を固定したものです。

### ① 理想条件で式を発見

既定値：m=1、k=4、c=0.3、x0=0.5、v0=0、20秒、記録周期0.1秒、学習割合0.65、候補3次、λ=0.03。
理想条件では正確な変位・速度・加速度を使用します。センサ記録のノイズは学習に影響しません。
10個の候補から x と v が残り、加速度の式は -4x -0.3v になります。
「推定ステップ」で全候補の最小二乗結果と、項を除いた後の係数を比較できます。

### ② 必要な項まで削る

理想条件のままλ=0.2にします。減衰のv項まで除去され、波形が減衰しなくなります。
この条件ではxの係数は再推定されて約-3.915となり、変位の検証RMSEは約0.314 mです。
λ=1.2にすれば全項が消える例も見られます。
「項が少なければよい」という判断では必要な関係も失うことを示せます。

### ③ ノイズと数値微分

変位センサの標準偏差0.01 m、記録周期0.1秒、シード42で、中央差分から速度・加速度を推定します。
余分な非線形項が残る例です。「数値微分で得た加速度」で真の加速度との差も確認できます。
このノイズは観測誤差であり、対象自体にランダムな外力を加えてはいません。

### ④ 平滑化して微分

③と同じセンサ記録を、11点の局所3次多項式で平滑化して微分します。
既定条件ではxとvだけが残りますが、係数は約-3.693、-0.256となり、真値に一致するわけではありません。
平滑化はノイズを抑える一方で信号を変形し、窓幅によっても結果が変わります。予測精度が常に改善するわけではありません。

## 学習の範囲と実装

- 既知の運動学 ẋ=v を固定し、v̇の式を探索するSINDyのSTLSQデモです。2本の微分方程式を両方ともゼロから発見する設定ではありません。
- 候補は1、x、v、x²、xv、v²、x³、x²v、xv²、v³。最高次数を1〜3から選べます。
- 全候補を最小二乗推定し、小さい係数の項を除去し、残った項を再推定します。除外した項は再投入しません。
- 候補列と加速度を学習区間のRMSで正規化し、無次元の係数にλを適用します。表示する方程式の係数は元の単位へ戻します。
- 記録済みの前半（既定65%）だけで学習します。平滑化と微分も分割後の学習データだけで行い、検証区間を使いません。
- 差分では両端1点、局所多項式では両端に窓の半分の点を除きます。平滑化は前後の点を使うオフライン処理です。
- 候補数に対して学習点が不足する場合、信号がほぼ0の場合は、条件変更を促すメッセージを表示します。階数不足や強い悪条件も知らせます。
- 再計算には、学習した加速度式と既知のẋ=vをRK4で積分します。内部刻みは0.005秒以下です。初期条件は設定値を共通に与え、時刻0から検証終了まで観測による補正をせず計算します。
- 真値はセンサ条件での学習には使いません。真の式の表示・微分誤差・変位の検証誤差は仮想実験での比較用です。
- 発散時は計算を打ち切り、以降の予測を欠損、検証誤差をinfにします。グラフは記録が見える範囲に固定し、範囲外をメッセージで知らせます。
- 式から分かるのはk/m・c/mの比です。m・k・cをそれぞれ特定したことにはなりません。
- 単一軌道に合うことだけで他の初期条件での妥当性は保証されません。検証画面を見て調整した後は、別の軌道でも確認が必要です。

## 二次の復元力を加える追加版

真のモデルに `m x'' + c x' + k x + q x² = 0` を選べます。
左パネル「真の復元力に二次項を含める」でオン・オフ、「二次の復元力係数 q」で大きさと符号を変更します。
学習側の「候補項の最高次数」は独立した設定です。

- ⑤ 二次項を発見：m=1, k=4, c=0.3, q=2, x0=0.5, v0=0、理想条件、候補2次、λ=0.03。
  正解は `v' = -4x -0.3v -2x²` です。
- ⑥ 二次項を候補から外す：同じ真の対象のまま候補1次に制限します。
  欠けた二次項を表現できず、線形係数も再調整され、波形がずれます。
- 真の二次項をオフにすれば元の線形モデルに戻ります。

二次項を加えた復元力は左右非対称になります。表示する固有周期・減衰比はx=0付近の線形化に基づく目安です。
真の非線形軌道もRK4で計算し、台車・グラフ・記録・学習・答え合わせのすべてに同じ軌道を使います。
台車の表示倍率はその計算区間の軌道に合わせて決まり、再生中は固定されます。
二次の復元力だけではすべての変位で安定とは限りません。運動が非有界となり数値計算が継続できない条件では、メッセージを表示して停止します。
線形モデルは従来どおり解析解を使用します。
