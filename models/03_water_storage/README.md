# 貯留と流出による水位の時間変化

第5回の講義資料p.8の2段貯留モデルを使用した、確定的な1本の水位変化のデモです。

## 起動

Python 3.14で動作確認しています。このフォルダで次を実行します。

```sh
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

Cloudではapp.pyと同じフォルダにmodel.pyとrequirements.txtを配置してください。

## モデル

- dS/dt = A r_e − Q_in、Q_in = S/τc
- dV/dt = Q_in − Q_out、Q_out = V/τr
- h = h0 + V/Ar

S,Vはm³、A,Arはm²、r_eはm/s、τは秒、h,h0はmです。
左パネルのkm²、万m²、mm/h、時間を内部でSI単位へ換算します。
流域の初期貯留は等価水深[mm]で指定し、面積を掛けてS0[m³]へ換算します。
h0は換算の基準水位であり、初期水位ではありません。初期水位はh0+V0/Arです。

有効降雨は三角形の波形を直接指定します。開始時刻、ピーク強度、継続時間を変更できます。
時刻0から雨が終わった後まで積分し、降雨がない場合でも初期貯留から流れが生じます。
内部では10秒以下の区間で有効降雨を区間中点の値で一定近似し、線形連立式を解析的に更新します。
降雨開始・ピーク・終了を区間境界に含めるため、入力降雨の総量も整合します。τc=τrにも対応します。

## 操作

- 左パネルのモデル条件を変えると時刻0へ戻って停止します。
- 再生、一時停止、先頭へ戻る、時刻指定、全時間表示が可能です。
- 1倍ではモデルの1時間を約20秒で再生します。
- スライダーは時刻指定用です。再生位置は現在時刻の数値とグラフの縦線で示します。
- 表示する基準水位はモデルの流れや貯留量に影響しません。
- 流域と河道の水面表示は異なる尺度です。再生中はそれぞれの表示倍率を固定します。
- 河道の灰色領域は水位の基準h0以下で、その上の水色の部分が貯留Vに対応します。
- 下の折り畳み欄で降雨、流量、貯留量の推移、水収支を確認できます。
- 全時間表示後は最高水位・その時刻の表示、CSV保存ができます。

## 設定例

① 降雨から水位への遅れ：既定条件。降雨ピーク1.5時間に対し水位ピークは約2.33時間、最高水位は約1.48 mです。
② 流域からゆっくり流出：τcを2時間へ変更します。
③ 河道から抜けにくい：τrを1.5時間へ変更します。
④ 雨がなくても貯留から流れる：有効降雨を0にし、初期貯留からの流出を確認します。

流域面積を変えると、同じ降雨強度でも総入力水量が変わります。また初期貯留の等価水深を固定したまま面積を変えるとS0の水量も変わります。
河道の有効水面積はVからhへの換算に使用します。固定した初期V0ではAr変更により初期水位も変わります。

これは潮位、背水、氾濫を扱わない授業用モデルです。基準水位を超えても流域・河道の式は変わらず、その後も計算を継続します。
